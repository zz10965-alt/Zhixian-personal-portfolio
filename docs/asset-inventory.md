Status distinctions:

- **Already integrated**: an existing or recovered resource is used by the website or review documentation.
- **Found**: accessible, with the action column explaining stored-but-not-displayed, duplicate, unrelated or intentionally excluded resources.
- **Unverified**: original URL/asset exists, but live verification is blocked or identity/availability has not been confirmed. Retained in metadata; unverified interactive actions remain hidden.
- **Inaccessible**: previously supplied inline material or explicitly referenced prior file cannot be retrieved in this context. Referenced evidence is not proof it was uploaded to this particular chat.
- **Not found**: no matching file in the checked sources. For photos/logos the accessible record contains no evidence they were provided; this is not a claim about other conversations. Named absent deliverables are distinguished from never-provided files.
